# Techfest IIT Bombay — Ideate Landing Page

A no-3D, responsive landing page concept for the Techfest College Ambassador **Ideate Landing Page** task.

## Concept
**WHERE IDEAS TAKE OFF.**

The design uses bold editorial typography, Techfest-inspired red/black/cream contrast, scroll reveal animation, a moving ticker, interactive cards, ecosystem sections and responsive layouts. No 3D assets are used.

## Official research
The current Techfest website was reviewed before designing this concept. The current ecosystem includes competitions/ideates and workshops across AI & Data, Technology & Cybersecurity, Business/Finance/Management, Design & Creative Technology, and Engineering & Robotics. Techfest's CA page describes the festival as its 30th edition with 1,80,000+ footfall across 3 days and 300+ events.

## Tech
HTML5, CSS3, Vanilla JavaScript. No framework.

## Run
Open `index.html` in a browser or use VS Code Live Server.
